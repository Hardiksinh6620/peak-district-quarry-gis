# Peak District quarry scenarios

A group GIS project examining terrain and potential quarry scenarios around Longstone Edge in the Peak District.

Original group authors: **Mathu Kasthuri Ashokakumar, Hardiksinh Ajaysinh Parmar, and Vaisak Balachandran**. The report contract attributes Hardiksinh to data collection, identification of major study-area features, hillshade analysis, and progress coordination. Other outputs retain group attribution.

This repository contains a privacy-safe copy of the final report plus explanatory notes and small educational checks created for the portfolio edition. Original GIS projects and source datasets were not supplied.
