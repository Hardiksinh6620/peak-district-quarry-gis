# Viewshed assumptions and limitations

A viewshed depends on the elevation surface, observer location and height, target height, maximum distance, Earth-curvature treatment, and obstructions represented by the input surface. The report provides a conceptual description but not a complete recoverable parameter set.

Visibility from a modeled point is not equivalent to landscape impact, public acceptance, or land stability. A later analysis should compare modeled visibility with selected field observations where possible and explain whether vegetation and buildings are represented.

The group contract assigns viewshed analysis to another contributor, so this repository keeps it within the shared project rather than presenting it as Hardiksinh's individual method.
