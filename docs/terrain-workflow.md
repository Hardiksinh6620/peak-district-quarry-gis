# Terrain workflow and parameter inventory

The report discusses slope, aspect, contours, hillshade, viewshed, and 3D visualization. A reproducible workflow needs the elevation dataset, horizontal and vertical coordinate systems, cell size, units, resampling, processing extent, NoData handling, observer settings, illumination angles, and output classifications.

The final PDF does not preserve all these values. Do not select defaults retrospectively and describe them as original parameters. Recover the ArcGIS project or source raster where possible; otherwise label any rerun as a later recreation using replacement data.

Check that vertical and horizontal units are compatible before calculating slope or hillshade. Record whether slope is expressed in degrees or percent.
